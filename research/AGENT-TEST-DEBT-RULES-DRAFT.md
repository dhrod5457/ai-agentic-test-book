# Agent Test Debt Rules Draft\n\n상태: 연구 기반 초안\n기준일: 2026-10-05\n\n## New Test Admission\n\n새 테스트는 다음 조건 중 하나를 만족해야 한다.\n- 새로운 failure mode 검증\n- 새로운 boundary/invariant 검증\n- 기존 회귀 재현\n- 새로운 integration/contract boundary 검증\n\n단순 coverage 증가만으로는 승인하지 않는다.\n\n## Duplicate Rule\n\n동일한 목적의 테스트가 있으면 새 테스트보다 기존 테스트 보강을 우선한다.\n\n## Brittle Rule\n\nobservable behavior보다 내부 구현 세부를 검증하지 않는다.\n\n## Mock Rule\n\nmock으로 제거한 실제 경계가 어디에서 integration test로 검증되는지 명확해야 한다.\n\n## Fixture Rule\n\nfixture는 최소 데이터만 포함한다.\nglobal mutable fixture를 사용하지 않는다.\n\n## Disabled Rule\n\nAgent는 임의로 테스트를 disable/ignore하지 않는다.\n\n## Cleanup Rule\n\n테스트 추가로 다음이 발생하면 정리 작업을 함께 수행한다.\n- duplicate fixture\n- duplicate assertion pattern\n- obsolete test\n- unused helper\n- unnecessary mock\n\n## Maintenance Metrics\n\n- total test count\n- unique failure-mode count\n- p50/p95 duration\n- duplicate test candidates\n- disabled test count\n- flaky test count\n- smell count\n- mutation score\n\n테스트 수 증가 자체는 성공 지표가 아니다.
